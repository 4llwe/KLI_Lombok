# Academic Release Checklist

## Form dan konten
- [ ] Intended use serta target population jelas.
- [ ] Blueprint dan bobot berjumlah 100%.
- [ ] Jumlah item/tugas memenuhi minimum.
- [ ] Semua item memiliki competency tag, satu jawaban terbaik, dan distraktor masuk akal.
- [ ] Stimulus orisinal dan hak penggunaannya terdokumentasi.
- [ ] Audio final direkam dan diperiksa; transcript tidak tampil saat tes validated.
- [ ] Rubrik serta level descriptors sesuai tujuan.

## Review
- [ ] Content review oleh ahli bahasa.
- [ ] Level review oleh reviewer berbeda.
- [ ] Language editing dan bias/accessibility review.
- [ ] Technical QA pada desktop/mobile.
- [ ] Keputusan revision_required ditutup.

## Pilot dan psikometrik
- [ ] Minimal 30 peserta unik; target 100+.
- [ ] Statistik item dan reliability dihitung.
- [ ] Item lemah ditinjau dan versi diperbarui.
- [ ] Dual-rating agreement diperiksa.
- [ ] Cut score ditetapkan dan didokumentasikan.
- [ ] Psychometric review disetujui.

## Klaim dan publikasi
- [ ] Status database `approved` dan `validated`.
- [ ] Limitations tampil pada laporan hasil.
- [ ] Tidak ada klaim resmi/afiliasi yang menyesatkan.
- [ ] Masa berlaku, jadwal revalidasi, dan pemilik form dicatat.
