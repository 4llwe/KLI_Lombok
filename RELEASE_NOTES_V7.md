# Release Notes V7 — English Institutional Proficiency Practice

## New publishable practice form

- Added `EN-ITP-SR-DIAGNOSTIC` with 90 KLI-original objective items.
- Structure and Written Expression: 40 items / 25 minutes.
- Reading Comprehension: 50 items / 55 minutes across five original passages.
- Added section headers and one-time passage rendering in the test player.
- Preserved fixed question and option order where form integrity requires it.
- Added server delivery of section and stimulus metadata without exposing answer keys.

## Academic corrections

- Standardized Structure to 15 sentence-completion and 25 error-identification items.
- Ensured each Written Expression item has one defensible error.
- Corrected ambiguous collocations and concessive constructions.
- Replaced incomplete reading questions with four-option items and functioning distractors.
- Removed external institution branding and official-score claims.

## Scope

This release is publishable as commercial preparation practice. It is not a complete TOEFL ITP simulation and must not be represented as an ETS score. Listening remains outside the live form until licensed audio is mapped to matching questions, transcripts, timestamps, and independently verified answer keys.
